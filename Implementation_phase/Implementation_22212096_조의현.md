## 2. Project Overview

컴퓨터공학 핵심 과목인 '자료구조와 알고리즘'의 동작 원리를 게임의 스킬과 기믹을 치환하여, 플레이어가 직접 체험하며 학습할 수 있도록 구현한 턴제 RPG 시스템입니다.
- 프로젝트명: 알고리즘 용사 (Algorithm Hero)
- 장르: 자료구조/알고리즘 기반 로그라이크 턴제 RPG
- 플랫폼: PC (Windows 스탠드얼론)
- 사용 엔진 및 언어: Unity 6000.4.0f1 / C# (.NET Standard)
- 핵심 시스템: 정렬 알고리즘(버블, 선택, 삽입)의 원리를 반영한 블록 스왑/시프트 전투 로직
	- 자료구조(스택, 큐)의 LIFO, FIFO 특성을 반영한 방어막 덱빌딩 시스템
